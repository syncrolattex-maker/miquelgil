1. **Plan 002 (Performance)**: First clean up `transition: all` across `contractacio.css` so subsequent CSS additions build on targeted property transitions.
2. **Plan 001 (Modal Exit Easing)**: Fixes the feel-breaking lag when closing the booking modal in `ContractacioClient.tsx`.
3. **Plan 004 (Tactile Press Feedback)**: Adds `:active` compression states in `contractacio.css` for cards and pills.
4. **Plan 005 (Close Button Refinement)**: Eliminates cartoon bounce and 90° glyph morphing in modal close control.
5. **Plan 003 (Reduced Motion)**: Adds accessibility gates in both `ContractacioClient.tsx` and `contractacio.css` wrapping the settled animations.

*No plans have blocking hard dependencies, but executing in this order produces the cleanest diffs.*
